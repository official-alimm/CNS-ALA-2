KNOWLEDGE BASE

Reports & Learning

Download a summary of the experiment and event log for your GMIU practical submission.

01 · Virus

A virus attaches to a host file or program and may spread when the host is executed or shared. Possible impacts include data loss, file corruption and interrupted work.

Defense: trusted security software, scanning, backups and cautious file sharing.

02 · Worm

A worm can propagate between systems without attaching to a host file. Some worms exploit vulnerabilities and may consume bandwidth or disrupt services.

Defense: patching, network segmentation, monitoring and access controls.

03 · Trojan Horse

A Trojan disguises itself as legitimate software. It relies on deception and may perform unauthorized actions if trusted and run.

Defense: verify publishers, review permissions and use trusted download sources.

Practical conclusion

This project demonstrates the conceptual differences between viruses, worms and Trojan horses through fictional, step-by-step models. It reinforces the importance of software updates, least privilege, verified downloads, backups and user awareness.
